# GLM 4.5: Zhipu AI's Dual-Mode Reasoning MoE Model

## Model Overview
**GLM 4.5** is Zhipu AI's flagship open-weights Mixture-of-Experts language model, released in July 2025. With 355 billion total parameters and 32 billion active during inference, GLM 4.5 features a dual-mode reasoning system supporting both fast non-thinking responses and deep agentic thinking modes. It unifies reasoning, coding, and autonomous action capabilities with native tool use and multi-agent workflow support, all under an MIT license.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **Dual-Mode Reasoning** | Supports both fast non-thinking mode and deep agentic thinking mode |
| **355B MoE (32B Active)** | Efficient MoE architecture — frontier capability at reduced inference cost |
| **128K Context** | Extended context window for complex multi-turn tasks |
| **Native Tool Use** | Built-in tool use and function calling capabilities |
| **Multi-Agent Support** | Native support for multi-agent workflow orchestration |
