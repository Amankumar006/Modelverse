# Gemini 3.5 Flash-Lite: Google's Most Cost-Efficient Gemini

## Model Overview
**Gemini 3.5 Flash-Lite** is Google DeepMind's most cost-efficient model in the new July 2026 Gemini release batch, released on **July 21, 2026** alongside Gemini 3.6 Flash and Gemini 3.5 Flash Cyber. Designed for high-volume, cost-sensitive deployments where economy and speed are the priority, it retains multimodal input capabilities and the 1M token context window from the broader Gemini 3.5 family while offering the lowest price per token of the batch.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **Most Cost-Efficient** | Lowest price per token in the July 2026 Gemini release batch |
| **Multimodal Input** | Accepts text, image, audio, and video inputs |
| **1M Token Context** | Full long-context capabilities for document-heavy tasks |
| **High Throughput** | Optimized for high-volume, low-latency deployments at scale |
| **Gemini Ecosystem** | Full compatibility with Gemini API tools, function calling, and grounding |
