# GPT-4o: OpenAI's Flagship Omnimodal Model

## Model Overview
**GPT-4o** ("omni") is OpenAI's most advanced and flagship multimodal large language model, first released in May 2024. It accepts any combination of text, audio, image, and video as input, and produces text, audio, and image outputs. GPT-4o matches GPT-4 Turbo's performance on intelligence benchmarks while being significantly faster and cheaper, with native multimodal understanding across all modalities in a single unified model — rather than relying on separate pipeline models for each modality.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **Omnimodal** | Native understanding of text, audio, image, and video input in one unified model |
| **Real-Time Voice** | Processes audio with near-human latency (~232ms), understanding tone, emotion, and non-verbal cues |
| **Vision Understanding** | Analyzes images, charts, screenshots, and documents with state-of-the-art accuracy |
| **Multilingual** | Significantly improved performance across 50+ non-English languages |
| **API Efficiency** | 2x faster and 50% cheaper than GPT-4 Turbo with comparable intelligence benchmarks |

## 📊 Benchmarks

| Benchmark | Score | Notes |
|:---|:---:|:---|
| MMLU (5-shot) | 88.7% | Zero-shot matches GPT-4 Turbo 5-shot |

| MATH | 76.6% | Significant improvement vs GPT-4 Turbo |
