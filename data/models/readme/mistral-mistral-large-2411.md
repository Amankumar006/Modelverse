# Mistral Large 2.1

## 📌 Model Overview

Flagship Mistral model for advanced reasoning, coding, and multilingual work

**Mistral Large 2.1** is a **Open Weights** model developed by **Mistral AI**, released on **2024-11-18**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **131K tokens** context window and **Undisclosed** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
