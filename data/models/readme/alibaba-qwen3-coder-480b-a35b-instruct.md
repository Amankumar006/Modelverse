# Qwen3-Coder 480B-A35B Instruct

## 📌 Model Overview

Open Qwen coding heavyweight for repository reasoning and agentic engineering

**Qwen3-Coder 480B-A35B Instruct** is a **Open Weights** model developed by **Alibaba**, released on **2025-04-01**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **262K tokens** context window and **480B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
