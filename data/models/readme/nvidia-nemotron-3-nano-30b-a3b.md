# Nemotron 3 Nano 30B A3B

## 📌 Model Overview

Small Nemotron 3 MoE for efficient coding, math, and long-context agents

**Nemotron 3 Nano 30B A3B** is a **Open Weights** model developed by **NVIDIA**, released on **2025-12-15**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **262K tokens** context window and **30B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
