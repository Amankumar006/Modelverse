# Pixtral 12B

## 📌 Model Overview

Mistral vision-language model for image understanding and multimodal chat

**Pixtral 12B** is a **Open Weights** model developed by **Mistral AI**, released on **2024-09-01**. It is designed primarily for **Multimodal General** workloads. Featuring a **128K tokens** context window and **12B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
