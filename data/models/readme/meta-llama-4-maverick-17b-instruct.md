# Llama 4 Maverick 17B Instruct

## 📌 Model Overview

Open multimodal Llama for strong reasoning with efficient everyday serving

**Llama 4 Maverick 17B Instruct** is a **Open Weights** model developed by **Meta**, released on **2025-04-05**. It is designed primarily for **Multimodal General** workloads. Featuring a **1M tokens** context window and **17B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
