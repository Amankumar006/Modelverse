# Nemotron Nano 12B v2 VL

## 📌 Model Overview

Nemotron multimodal model for visual reasoning and agentic AI workflows

**Nemotron Nano 12B v2 VL** is a **Open Weights** model developed by **NVIDIA**, released on **2025-10-28**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **128K tokens** context window and **12B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
