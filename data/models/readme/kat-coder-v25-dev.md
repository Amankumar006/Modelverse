# KAT-Coder-V2.5-Dev

## Model Overview
**KAT-Coder-V2.5-Dev** is a **34.7B-parameter** Mixture-of-Experts text generation model developed by **Kwaipilot**. Built on the `Qwen3_5MoeForConditionalGeneration` architecture. Supports en, zh. Released on **2026-07-23**.

- 34.7B parameters with sparse MoE architecture for efficient inference
