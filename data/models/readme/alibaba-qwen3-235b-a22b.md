# Qwen3 235B-A22B

## 📌 Model Overview

Large open Qwen MoE for multilingual reasoning, coding, and tool use

**Qwen3 235B-A22B** is a **Open Weights** model developed by **Alibaba**, released on **2025-04-01**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **131K tokens** context window and **235B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
