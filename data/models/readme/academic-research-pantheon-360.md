# Pantheon 360

## 📌 Model Overview

Developed by USC, NYCU, Cornell, and Bosch Research (CVPR 2026), Pantheon 360 is a 3D-aware 360° video diffusion framework that utilizes an explicit 3D Cache to synthesize geometrically consistent panoramic videos and digital twins.

**Pantheon 360** is a **Research Preview** model developed by **Academic/Research**, released on **2026-05-26**. It is engineered primarily for **Video Generation** workloads. Featuring a **128K tokens** context window and **Undisclosed** parameter count, it offers robust performance for enterprise integration, developers, and researchers.

---

## ✨ Key Features & Capabilities

| Feature | Description |
|:---|:---|
| **Context Window** | 128K tokens capacity for extended prompts and multi-turn workflows |
| **Primary Task** | Optimized for Video Generation |
| **Deployment** | self-hostable |
| **Modality** | text, image, video |
| **Capability** | 3D-aware 360° video diffusion from single or sparse panoramic images |
| **Capability** | Explicit 3D Cache acting as a geometric scaffold for camera trajectory control |
| **Capability** | Eliminates temporal drift and cross-view inconsistency inherent in narrow-FoV video generators |
| **Capability** | First video diffusion model supporting seamless 360° video interpolation and long-horizon synthesis |
| **Capability** | Applications in digital twin creation, camera motion stabilization, and Street View enhancement |
