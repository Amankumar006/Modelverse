# Solar-Open2-250B-Nota-NVFP4

**Solar-Open2-250B-Nota-NVFP4** is a **144.6B-parameter** Mixture-of-Experts text generation model developed by **nota-ai**. Built on the `SolarOpen2ForCausalLM` architecture. Supports en, ko, ja. Released on **2026-07-21**.
