# Aya Expanse 32B

## 📌 Model Overview

Open multilingual model optimized for generation across 23 languages

**Aya Expanse 32B** is a **Open Weights** model developed by **Cohere**, released on **2024-10-24**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **128K tokens** context window and **32B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
