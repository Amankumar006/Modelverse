## Model Overview

GPT Dreaming is a specialized research-preview model and background memory system released by OpenAI on July 15, 2026. Designed to fundamentally change how AI models retain and integrate context over time, GPT Dreaming operates in the background to automatically synthesize, update, and prune conversational memory. By processing past interactions while the model is "asleep" (not actively engaged with the user), it builds a comprehensive, evolving profile of user preferences and projects.

## Capabilities

*   **Automated Background Synthesis:** Reviews and synthesizes past interactions in the background, consolidating experiences into long-term memory similar to human dreaming.
*   **Dynamic Memory Evolution:** Automatically updates, refines, or prunes stored information as user needs, projects, and life circumstances change, preventing memory from becoming stale.
*   **Deep Personalization:** Creates a rich, up-to-date context profile without requiring users to explicitly instruct the model on what to save.
*   **User-Controlled Context:** While automated, the system allows users to view, edit, or delete the synthesized memories to maintain complete control over their data.

## Example Use Cases

*   **Long-Term Project Assistance:** Keeping track of extensive coding projects, writing assignments, or research where context spans multiple days or weeks, allowing the model to recall previous decisions automatically.
*   **Personalized AI Companions:** Creating highly tailored conversational agents that naturally remember user preferences, conversational style, and past shared experiences.
*   **Continuous Learning Workflows:** Enabling enterprise tools to automatically adjust to evolving workflows and changing team dynamics by silently synthesizing daily interactions.

## Performance & Benchmarks

As a research preview focusing on memory architecture rather than raw generation capability, GPT Dreaming is evaluated on its ability to maintain contextual relevance over extended periods. Preliminary testing shows significant improvements over legacy "Saved Memories" features, with far fewer instances of hallucinated context or forgotten instructions over long conversational horizons. The exact parameter count and context window remain undisclosed.

## Intended Use & Limitations

GPT Dreaming is intended to test the viability of background processing for AI personalization and memory synthesis. It is designed to be self-hostable and serves as a testing ground for future memory architectures.
**Limitations:** As a research preview, the memory synthesis may occasionally misinterpret the importance of certain interactions or over-prune relevant details. Users must actively manage their memory settings if the automated system misaligns with their preferences.
