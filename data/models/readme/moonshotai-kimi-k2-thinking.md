# Kimi K2 Thinking

## 📌 Model Overview

Thinking Kimi model for slower research passes, planning, and hard technical questions

**Kimi K2 Thinking** is a **Open Weights** model developed by **Moonshot AI**, released on **2025-11-06**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **262K tokens** context window and **Undisclosed** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
