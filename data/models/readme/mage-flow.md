# Mage-Flow

## 📌 Model Overview

Mage-Flow is a 4.1B-parameter text to image model developed by microsoft. Released on 2026-07-21 with 242 likes and 891 downloads on Hugging Face.

**Mage-Flow** is a **Open Weights** model developed by **microsoft**, released on **2026-07-21**. It is engineered primarily for **Image Generation** workloads. Featuring a **unknown** context window and **4.1B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
