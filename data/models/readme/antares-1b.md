# antares-1b

## 📌 Model Overview

antares-1b is a 1.8B-parameter text generation model developed by fdtn-ai. Built on the GraniteMoeHybridForCausalLM architecture using transformers. Supports en language(s). Released on 2026-07-21 with 150 likes and 4,266 downloads on Hugging Face.

**antares-1b** is a **Open Weights** model developed by **fdtn-ai**, released on **2026-07-21**. It is engineered primarily for **Chat Reasoning** workloads.
