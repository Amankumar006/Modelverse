# Nano Banana 2 Lite (Gemini 3.1 Flash-Lite Image)

## 📌 Model Overview

**Nano Banana 2 Lite** (Gemini 3.1 Flash-Lite Image) is Google DeepMind's fastest and most cost-efficient image generation model designed for high-volume 1K image rendering, multi-turn image editing, and real-time interactive design applications.

Featuring native **Thinking On** reasoning, it follows complex prompt instructions with high spatial accuracy and consistent subject rendering at an ultra-fast generation latency of **4.0 seconds per 1K image**.

---

## ✨ Key Features & Capabilities

| Feature | Details |
|:---|:---|
| **Ultrafast Latency** | **4.0s per 1K resolution image** generation latency (5x faster than Nano Banana 2) |
| **High Quality Benchmark** | **1251 Image Gen Elo** & **1308 Image Edit Elo** on LMArena |
| **Native Thinking On** | Integrated multi-step chain-of-thought reasoning for precise composition and layout control |
| **Multi-Turn Editing** | High-fidelity subject consistency and localized image modifications across continuous conversations |
| **Cost Efficiency** | **$0.034 per 1K resolution image**, offering 50% savings compared to standard Flash image models |
| **Context Window** | 66K token input capacity supporting complex prompt descriptions and multi-image inputs |
