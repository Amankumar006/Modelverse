# Solar-Open2-250B

## 📌 Model Overview

Solar-Open2-250B is a 250.3B-parameter Mixture-of-Experts (MoE) text generation model developed by upstage. Built on the SolarOpen2ForCausalLM architecture using transformers. Supports en, ko, ja language(s). Released on 2026-07-22 with 543 likes and 1,106 downloads on Hugging Face.

**Solar-Open2-250B** is a **Open Weights** model developed by **upstage**, released on **2026-07-22**. It is engineered primarily for **Chat Reasoning** workloads. Featuring a **unknown** context window and **250.3B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
