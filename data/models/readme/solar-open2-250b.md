# Solar-Open2-250B

## Model Overview
**Solar-Open2-250B** is a **250.3B-parameter** Mixture-of-Experts text generation model developed by **upstage**. Built on the `SolarOpen2ForCausalLM` architecture. Supports en, ko, ja. Released on **2026-07-22**.
