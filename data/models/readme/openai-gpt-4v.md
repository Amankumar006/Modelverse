# GPT-4V: OpenAI's Vision-Capable Language Model

## Model Overview
**GPT-4V** (GPT-4 with Vision) extends the GPT-4 language model with the ability to accept image inputs alongside text, enabling multi-modal understanding and reasoning. Released in September 2023, GPT-4V represents a significant step forward in large language model capabilities by allowing users to ask questions about and reason over visual inputs including photographs, charts, diagrams, and screenshots.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **Image Understanding** | Analyzes and reasons about photos, documents, charts, screenshots, and diagrams |
| **OCR Capabilities** | Reads and interprets text within images |
| **Multi-Image Support** | Can process multiple images in a single conversation turn |
| **Scientific Analysis** | Interprets scientific figures, graphs, and mathematical notation in images |
| **GPT-4 Intelligence** | Full GPT-4 reasoning capability extended to multimodal inputs |
