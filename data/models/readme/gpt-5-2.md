# GPT-5.2

## Model Overview
GPT-5.2 is an advanced frontier model released by OpenAI on December 11, 2025. Designed for professional knowledge work, complex reasoning, and long-running agentic tasks, this model features a 400,000-token context window and up to 128,000 output tokens. It introduces "Adaptive Reasoning," allowing it to dynamically allocate computational resources based on query complexity. GPT-5.2 is available in three primary variants: Instant, Thinking, and Pro, allowing users to balance speed and analytical depth. *Note: As of July 2026, it is considered a legacy model and has been succeeded by newer releases in the GPT-5 family.*

## Capabilities
*   **Adaptive Reasoning:** Dynamically adjusts "reasoning effort" levels (e.g., none, low, medium, high, xhigh) to allocate computational resources effectively.
*   **Three-Tier System:** 
    *   **Instant:** Optimized for speed and everyday tasks.
    *   **Thinking:** Designed for deep logic and complex troubleshooting.
    *   **Pro:** Engineered for the highest accuracy in enterprise workloads.
*   **Massive Context:** Supports a 400,000-token context window and up to 128,000 output tokens.
*   **Multimodal Input:** Capable of processing complex multimodal inputs including text, code, and technical diagrams.

## Example Use Cases
*   **Complex Problem Solving:** Utilizing the Thinking variant for deep logical analysis and troubleshooting.
*   **Enterprise Workloads:** Leveraging the Pro variant for high-accuracy data analysis and professional knowledge work.
*   **Agentic Workflows:** Running long-horizon, autonomous tasks that require consistent tracking of project states over extended periods.

## Performance & Benchmarks
GPT-5.2 set multiple performance records at the time of its release:
*   **Software Engineering:** Achieved 55.6% on SWE-Bench Pro and 80% on SWE-Bench Verified.
*   **Mathematical/Scientific Reasoning:** Scored a perfect 100% on AIME 2025 and 93.2% on GPQA Diamond (PhD-level science).
*   **General Intelligence/Logic:** Reached over 90% on ARC-AGI-1 and 70.9% on the GDPval benchmark.
*   **Tool Use:** Achieved 98.7% accuracy on Tau2 Telecom tool-use tasks.

## Intended Use & Limitations
GPT-5.2 is intended for professional and enterprise environments requiring high levels of reasoning and accuracy. Limitations include increased latency and computational cost when using higher reasoning settings (like the Pro or Thinking tiers with xhigh effort). As a legacy model, users are generally advised to transition to more recent iterations, such as the GPT-5.6 family, for the latest improvements and support.
