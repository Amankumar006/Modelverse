# Nemotron 3 Nano Omni 30B A3B Reasoning

## 📌 Model Overview

Open Nemotron omni model combining reasoning with text, vision, and audio

**Nemotron 3 Nano Omni 30B A3B Reasoning** is a **Open Weights** model developed by **NVIDIA**, released on **2026-04-28**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **256K tokens** context window and **30B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
