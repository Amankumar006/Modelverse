# MiniMax M3: MiniMax's Frontier Multimodal Model

## Model Overview
**MiniMax M3** is MiniMax's latest flagship multimodal large language model. Building on MiniMax's previous models (MiniMax-Text-01 and MiniMax-VL-01), M3 delivers strong performance on reasoning, coding, and multimodal understanding tasks. Known for its extremely long context window capabilities and competitive performance on major benchmarks, MiniMax M3 is accessible via API and targets enterprise and developer use cases requiring powerful multimodal AI.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **Long Context** | Supports very long context windows — one of the leaders in this area |
| **Multimodal** | Text, image, and document understanding |
| **API Access** | Available for developers via MiniMax API platform |
| **Competitive Benchmarks** | Strong performance across coding, math, and reasoning benchmarks |
| **Enterprise Focus** | Designed for production-grade applications |
