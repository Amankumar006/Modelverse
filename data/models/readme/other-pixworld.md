# PixWorld: Pixel-Space 3D Scene Generator

## Model Overview
**PixWorld** is an open-source 3D scene generator that reconstructs fully consistent 3D environments directly in pixel space from one or multiple reference images. Unlike most 3D generation models that operate in latent space, PixWorld generates in pixel space — avoiding the visual artifacts that often result from latent-space reconstruction. A four-step version generates scenes in approximately 6 seconds at 480p resolution.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **Pixel-Space Generation** | Generates 3D scenes in pixel space, avoiding latent-space visual artifacts |
| **Fast Generation** | Four-step mode generates scenes in ~6 seconds at 480p |
| **Multi-Image Input** | Reconstructs consistent 3D environments from one or multiple reference images |
| **Open-Source Roadmap** | Full release plan including datasets and inference code |
| **Consistent 3D** | Maintains full 3D consistency across generated views |
