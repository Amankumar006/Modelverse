# GLM-5.2

## Model Overview
**GLM-5.2** is a **753.3B-parameter** Mixture-of-Experts text generation model developed by **zai-org**. Built on the `GlmMoeDsaForCausalLM` architecture. Supports en, zh. Released on **2026-06-16**.
