# Inkling-Small

## Model Overview
**Inkling-Small** is a **266.0B-parameter** Mixture-of-Experts image text to text model developed by **thinkingmachines**. Built on the `InklingForConditionalGeneration` architecture. Released on **2026-07-27**.
