# LFM2.5-2.6B

## Model Overview
**LFM2.5-2.6B** is a **2.7B-parameter** text generation model developed by **LiquidAI**. Built on the `Lfm2ForCausalLM` architecture. Supports ar, zh, en, fr, de, hi, id, it, ja, ko, pl, pt, ru, es, th, vi. Released on **2026-07-28**.
