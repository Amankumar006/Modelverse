# Hy3 preview

## 📌 Model Overview

Tencent Hy reasoning model for coding, instruction following, and agent tasks

**Hy3 preview** is a **Open Weights** model developed by **Tencent**, released on **2026-04-20**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **256K tokens** context window and **Undisclosed** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
