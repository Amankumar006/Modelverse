# Command R+: Cohere's RAG-Optimized Enterprise LLM

## Model Overview
**Command R+** is Cohere's most powerful enterprise-grade large language model, released in April 2024. Designed specifically for retrieval-augmented generation (RAG) and enterprise workflows, Command R+ features 104 billion parameters and state-of-the-art performance on tasks requiring grounded, citation-aware responses. It includes native multi-step tool use, multilingual support across 10 languages, and is optimized for deployment in production enterprise settings.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **RAG Specialist** | Optimized for retrieval-augmented generation with built-in citation and grounding |
| **Multi-Step Tool Use** | Performs complex agentic tasks using multiple tools in sequence |
| **Multilingual** | Supports 10 key enterprise languages including French, Spanish, German, Japanese, Korean, Arabic |
| **Long Context** | 128K token context window for processing large document collections |
| **Enterprise Ready** | Designed for production deployment with Cohere's enterprise support infrastructure |
