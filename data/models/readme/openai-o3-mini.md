# o3-mini

## 📌 Model Overview

Smaller o-series reasoner for economical coding, math, and planning tasks

**o3-mini** is a **Api Only** model developed by **OpenAI**, released on **2024-12-20**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **200K tokens** context window and **Undisclosed** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
