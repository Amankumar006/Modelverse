# Mira: Real-Time Multiplayer World Model

## Model Overview
**Mira** is a real-time multiplayer simulation model that acts entirely as a video generator responding to live user key presses, bypassing traditional pre-designed game engines. With 5 billion parameters trained on 10,000 hours of standard gameplay data, Mira renders physics, collisions, and environment changes on the fly — directly as video frames — and supports live four-player collaborative sessions at 20fps on a single B200 GPU.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **Real-Time Gameplay** | Generates 20 frames per second on a single NVIDIA B200 GPU |
| **Multiplayer Support** | Supports live four-player collaborative sessions in the same world |
| **Engine-Free** | Bypasses traditional game engines — renders physics and collisions purely via video generation |
| **10K Hours Training** | Trained on 10,000 hours of standard gameplay data |
| **5B Parameters** | Compact model delivering real-time performance |
