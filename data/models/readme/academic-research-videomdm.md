# VideoMDM

## 📌 Model Overview

VideoMDM is a diffusion-based framework that trains 3D human motion priors directly from accurate 2D poses extracted from monocular videos, without requiring any 3D ground truth.

**VideoMDM** is a **Open Weights** model developed by **Academic Research**, released on **2026-07-15**. It is engineered primarily for **Video Generation** workloads. Featuring a **128K tokens** context window and **Undisclosed** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
