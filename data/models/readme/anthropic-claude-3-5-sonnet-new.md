# Claude 3.5 Sonnet (new)

## Model Overview
Claude 3.5 Sonnet (new) is a major update to Anthropic's Claude 3.5 Sonnet line, officially released on October 22, 2024. While the original Claude 3.5 Sonnet was launched earlier in June 2024, this updated version introduced "Computer Use" to the public as a beta API capability. This groundbreaking feature allows the model to interact with a screen, cursor, and keyboard autonomously, functioning as an agentic tool.

## Capabilities
- **Computer Use (Public Beta):** The first model to support public beta computer use, enabling the AI to view screens, move cursors, click, and type just like a human user.
- **Improved Automated Coding:** Upgraded abilities in software engineering, debugging, and code generation.
- **Agentic Tooling:** Capable of autonomous task execution and navigating complex computer interfaces.
- **Multimodal Understanding:** Strong performance across text, image, and code processing with a 200K token context window.

## Example Use Cases
- **Autonomous Software Testing:** Navigating through applications to test UI elements and report bugs.
- **Data Entry & Management:** Automating repetitive tasks across different software applications and web browsers.
- **Advanced Coding Assistance:** Functioning as an AI software engineer that can read documentation, write code, and execute it within an IDE environment.
- **Workflow Automation:** Acting as an agent to streamline multi-step processes involving different desktop tools.

## Performance & Benchmarks
The updated Claude 3.5 Sonnet brought significant improvements in agentic and coding tasks compared to its predecessor. While specific parameter counts remain undisclosed, the model set new standards for autonomous computer use at the time of its release, showcasing advanced spatial and interface reasoning.

## Intended Use & Limitations
The model is deployed as an API-only service intended for enterprise developers, software engineers, and researchers. The "Computer Use" feature was released as an experimental beta, meaning it could occasionally make errors, hallucinate interface elements, or struggle with highly complex, non-standard UIs. Users are advised to employ it with supervision, especially for critical tasks.

## About Anthropic
Anthropic is an AI safety and research company based in San Francisco, founded by former OpenAI researchers. The company is dedicated to building reliable, interpretable, and steerable AI systems. Their Claude family of models is designed with a focus on constitutional AI and safety.
