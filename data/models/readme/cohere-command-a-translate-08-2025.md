# Command A Translate

## 📌 Model Overview

Translation model for multilingual conversion, localization, and cross-language workflows

**Command A Translate** is a **Open Weights** model developed by **Cohere**, released on **2025-08-28**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **8K tokens** context window and **Undisclosed** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
