# Codestral 22B: Mistral AI's Code-Focused LLM

## Model Overview
**Codestral 22B** is Mistral AI's first code-specialized language model, released in May 2024. With 22 billion parameters trained on a dataset of over 80 programming languages, Codestral is optimized for code generation, completion, infilling, and instruction following in coding contexts. It features a 32K token context window and supports fill-in-the-middle (FIM) tasks, making it particularly well-suited for IDE integration and coding assistants.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **80+ Languages** | Trained on Python, Java, C++, JavaScript, Bash, Go, SQL, and 74+ other languages |
| **Fill-in-Middle (FIM)** | Supports infilling for IDE-style code completion |
| **32K Context** | Long context for handling large files and multi-file codebases |
| **Fast Inference** | Smaller than many code models while maintaining competitive quality |
| **API Access** | Available via Mistral API (La Plateforme) and partners |
