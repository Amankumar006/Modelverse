# MiniMax-M2

## 📌 Model Overview

Efficient open MiniMax model built for coding agents and tool-heavy workflows

**MiniMax-M2** is a **Open Weights** model developed by **MiniMax**, released on **2025-10-27**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **197K tokens** context window and **Undisclosed** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
