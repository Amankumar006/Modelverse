# GPT Image 1

## Model Overview
**GPT Image 1** (`gpt-image-1`) is a natively multimodal image generation model developed by OpenAI, introduced in early 2025. Representing a significant architectural shift from prior diffusion-based models (such as DALL-E 2 and DALL-E 3), GPT Image 1 utilizes an **autoregressive architecture**. This means it processes and generates images by predicting tokens, analogous to how large language models predict text. It accepts both text and image inputs to produce high-quality visual outputs.

## Capabilities
* **Autoregressive Generation:** Uses token-based prediction for image creation rather than a traditional diffusion process.
* **Multimodal Inputs:** Accepts both text and image prompts, enabling versatile and responsive workflows.
* **Advanced Image Editing:** Supports inpainting, outpainting, and iterative multi-turn image editing.
* **Cost-Efficient Variants:** The model family includes `gpt-image-1-mini`, designed to offer a more affordable and efficient option for lightweight tasks.

## Example Use Cases
* **Iterative Design:** Multi-turn image editing where users refine concepts through continuous dialogue.
* **Content Creation:** Generating assets that require strict adherence to complex layout instructions.
* **Image Modification:** Inpainting missing sections or outpainting to seamlessly expand the borders of existing images.

## Performance & Benchmarks
GPT Image 1 demonstrated notable improvements over its predecessors in instruction following, layout adherence, and text rendering. Its autoregressive nature allows for more coherent structural layouts and better integration of textual elements within generated visuals compared to older diffusion models.

## Intended Use & Limitations
The model is intended for developers and creators needing programmatic access to advanced image generation via the OpenAI Images API and Responses API. While it was a strong performer upon its initial release, it has since been succeeded by newer models (such as GPT Image 1.5 and GPT Image 2) that offer enhanced speed and visual fidelity.
