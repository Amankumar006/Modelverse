# Unitree G1: Mass-Market Humanoid Robot

## Model Overview
**Unitree G1** is Unitree Robotics' mass-market humanoid robot designed for general-purpose applications, gymnastics, and high-precision task execution. First released in May 2024, the G1 features 29 to 43 degrees of freedom depending on configuration and 7-DoF arms for human-like manipulation and precision control. It has since gained global attention for its novel applications including VR-teleoperated surgical assistance, demonstrating the G1's versatility as an open-ecosystem humanoid platform.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **29–43 Degrees of Freedom** | Flexible configuration covering full body articulation |
| **7-DoF Arms** | Human-like arm movement enabling precise manipulation tasks |
| **VR Teleoperation** | Real-time teleoperation using onboard cameras and motion controllers |
| **Mass-Market Pricing** | Significantly more affordable than comparable humanoid robots at launch |
| **Open SDK** | Open development ecosystem for robotics researchers and developers |

---

## 🏥 Notable Application: Surgical Teleoperation

Unitree G1 was used by researchers at UCSD in a pioneering surgical teleoperation experiment — demonstrating the robot's precision and responsiveness suitable for medical applications when controlled via VR headset.
