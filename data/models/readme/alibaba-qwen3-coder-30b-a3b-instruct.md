# Qwen3-Coder 30B-A3B Instruct

## 📌 Model Overview

Smaller Qwen coder for efficient local agents and repo-level fixes

**Qwen3-Coder 30B-A3B Instruct** is a **Open Weights** model developed by **Alibaba**, released on **2025-04-01**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **262K tokens** context window and **30B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
