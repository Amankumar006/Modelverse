# GPT Live: OpenAI's Real-Time Voice Interface

## Model Overview
**GPT Live** is OpenAI's latest real-time voice interface, designed to enable natural, flowing conversation between users and AI. Unlike traditional voice assistants, GPT Live supports dynamic interruptions and natural conversation patterns, delegates complex reasoning tasks to stronger background models (like GPT 5.5), and can generate contextual visual UI responses — such as weather cards, stock charts, and maps — directly in the interface alongside voice responses.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **Natural Conversation** | Supports interruptions, pauses, and natural speech patterns |
| **Background Model Delegation** | Routes complex reasoning to more powerful backend models automatically |
| **Live Visual UI Cards** | Generates contextual UI elements (weather, stocks, maps) during voice conversations |
| **Low Latency** | Optimized for real-time response with minimal delay |
| **Multimodal** | Combines audio input/output with visual UI generation |
