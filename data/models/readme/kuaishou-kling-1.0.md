# Kling 1.0: Kuaishou's Video Generation Model

## Model Overview
**Kling 1.0** is Kuaishou's text-to-video and image-to-video generation model, released in June 2024. Developed by Kuaishou Technology, a major Chinese short-video platform, Kling can generate high-fidelity videos up to 2 minutes long at 1080p resolution and 30fps. It leverages a novel 3D spatiotemporal joint attention mechanism and a physical simulation approach to model realistic motion, making it one of the most capable video generation models at its release.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **2-Minute Videos** | Generates video clips up to 2 minutes long — longer than most contemporaries at release |
| **1080p / 30fps** | High definition output at full HD resolution |
| **Physical Simulation** | 3D spatiotemporal attention for realistic physics and motion |
| **Text + Image Input** | Supports both text-to-video and image-to-video generation |
| **5-Second Standard** | Default 5-second high-quality generation with smooth motion |
