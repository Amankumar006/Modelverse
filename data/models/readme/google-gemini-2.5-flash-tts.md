# Gemini 2.5 Flash TTS

## 📌 Model Overview

Speech generation model for controllable voice, narration, and audio delivery

**Gemini 2.5 Flash TTS** is a **Api Only** model developed by **Google DeepMind**, released on **2025-09-30**. It is designed primarily for **Audio Speech** workloads. Featuring a **33K tokens** context window and **Undisclosed** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
