# Inkling

## 📌 Model Overview

Inkling is a 952.4B-parameter Mixture-of-Experts (MoE) image text to text model developed by thinkingmachines. Built on the InklingForConditionalGeneration architecture using transformers. Released on 2026-07-14 with 1,547 likes and 27,883 downloads on Hugging Face.

**Inkling** is a **Open Weights** model developed by **thinkingmachines**, released on **2026-07-14**. It is engineered primarily for **Multimodal General** workloads. Featuring a **unknown** context window and **952.4B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
