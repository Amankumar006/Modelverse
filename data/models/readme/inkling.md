# Inkling

## Model Overview
**Inkling** is a **952.4B-parameter** Mixture-of-Experts image text to text model developed by **thinkingmachines**. Built on the `InklingForConditionalGeneration` architecture. Released on **2026-07-14**.

| **Architecture** | InklingForConditionalGeneration |

| **Modality** | text, image |
| **License** | APACHE-2.0 |
| **Framework** | transformers |
| **MoE** | Yes |
| **Languages** | — |

## ✨ Key Features

- 952.4B parameters with sparse MoE architecture for efficient inference
- Built on InklingForConditionalGeneration architecture (transformers)
- Primary task: image text to text (text, image modality)
- Open-weights under APACHE-2.0 license — self-hostable and fine-tunable
