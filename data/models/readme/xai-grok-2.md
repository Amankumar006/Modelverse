# Grok 2: xAI's Real-Time Reasoning Model

## Model Overview
**Grok 2** is xAI's second-generation large language model, released in August 2024. Grok 2 features significantly improved reasoning capabilities compared to Grok 1.5, along with multimodal vision understanding through the Grok-2 Vision variant. A key differentiator is its real-time access to X (Twitter) posts and the web, enabling Grok 2 to answer questions about current events without a knowledge cutoff. It was made available to X Premium and Premium+ subscribers.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **Real-Time X Access** | Direct access to live X posts — unique among major frontier models |
| **Vision Understanding** | Grok-2 Vision variant adds image analysis capabilities |
| **Improved Reasoning** | Significant step up in complex reasoning vs. Grok 1.5 |
| **FLUX Image Generation** | Integration with Black Forest Labs FLUX.1 for image generation |
| **API Access** | Available via xAI API for developers |
