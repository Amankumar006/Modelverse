# Aya Vision 32B

## 📌 Model Overview

Open multilingual vision model for OCR, visual reasoning, and image question answering

**Aya Vision 32B** is a **Open Weights** model developed by **Cohere**, released on **2025-03-04**. It is designed primarily for **Multimodal General** workloads. Featuring a **16K tokens** context window and **32B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.

---

## ✨ Key Features & Capabilities

| Feature | Description |
|:---|:---|
| **Context Window** | 16K tokens capacity for extended prompts and multi-turn workflows |
| **Primary Task** | Optimized for Multimodal General |
| **Deployment** | self-hostable, api-only |
| **Modality** | text, image |
| **Max Output** | Max Output: 4K tokens |
