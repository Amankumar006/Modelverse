# DeepSeek Coder V2 Instruct: Open-Source Code Model Rivaling GPT-4

## Model Overview
**DeepSeek Coder V2** is DeepSeek's second-generation code-focused language model released in June 2024. With 236 billion total parameters (21B active via MoE), it achieves performance competitive with GPT-4 Turbo on coding benchmarks while being fully open-source. Trained on 6 trillion tokens including 60% code data across 338 programming languages, DeepSeek Coder V2 supports math reasoning, code generation, debugging, and natural language understanding.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **236B MoE Architecture** | 236B total params, 21B active — efficient inference via Mixture-of-Experts |
| **338 Programming Languages** | Broadest language coverage of any code model at release |
| **GPT-4 Turbo Competitive** | Matches GPT-4 Turbo on major coding benchmarks |
| **128K Context** | Long context window for large codebase reasoning |
| **Open Source** | Fully open weights under DeepSeek license |
