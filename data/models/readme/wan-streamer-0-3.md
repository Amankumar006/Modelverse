# Wan Streamer v0.3

## 📌 Model Overview

Wan Streamer v0.3 learns video as a persistent world plus the events that unfold inside it, bringing free-form behavior to real-time audio-visual interaction.

**Wan Streamer v0.3** is a **Research Preview** model developed by **Alibaba Group**, released on **2026-07-16**. It is engineered primarily for **Video Generation** workloads. Featuring a **unknown** context window and **Undisclosed** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
