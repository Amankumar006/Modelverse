# Nemotron 3 Ultra 550B A55B

## 📌 Model Overview

Largest Nemotron 3 model for maximum open-weight reasoning and agent accuracy

**Nemotron 3 Ultra 550B A55B** is a **Open Weights** model developed by **NVIDIA**, released on **2026-06-04**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **1M tokens** context window and **550B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
