# GPT-4o mini

## 📌 Model Overview

Small omni GPT for cheap multimodal assistance and production-scale traffic

**GPT-4o mini** is a **Api Only** model developed by **OpenAI**, released on **2024-07-18**. It is designed primarily for **Multimodal General** workloads. Featuring a **128K tokens** context window and **Undisclosed** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
