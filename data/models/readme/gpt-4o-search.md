## Model Overview
Released on July 14, 2026 as a closed-source model, it is part of the broader GPT-4o model family but is specifically fine-tuned for tool use and web search grounding.## Capabilities
- **Real-Time Information Retrieval**: Optimized for extracting and synthesizing current information from the web.
- **Enhanced Tool Use**: Capable of effectively triggering web search tools during API conversations.
- **Text Modality**: Primarily handles text inputs and outputs, unlike the fully multimodal flagship GPT-4o model.

## Example Use Cases
- Real-time news aggregation and summarization.
- Answering user queries that rely on up-to-date information not found in the base training data.
- Search-augmented generation (RAG) within conversational AI applications.

## Performance & Benchmarks
While specific benchmark figures (such as parameters or context window size) are currently classified as "Unknown" by OpenAI, the model is noted to be highly efficient in managing search-related tool calls compared to standard general-purpose models.
