# VibeVoice-ASR-BitNet

## Model Overview
**VibeVoice-ASR-BitNet** is a **323M-parameter** automatic speech recognition model developed by **microsoft**. Built on the `VibeVoiceForASRTraining` architecture. Supports en, zh, fr, it, ko, pt, vi. Released on **2026-07-24**.
