# Llama 4 Scout 17B Instruct

## 📌 Model Overview

Open Llama with long-context vision for efficient multimodal agents

**Llama 4 Scout 17B Instruct** is a **Open Weights** model developed by **Meta**, released on **2025-04-05**. It is designed primarily for **Multimodal General** workloads. Featuring a **3.5M tokens** context window and **17B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
