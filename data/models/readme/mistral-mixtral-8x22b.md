# Mixtral 8x22B: Mistral AI's Sparse Mixture-of-Experts Model

## Model Overview
**Mixtral 8x22B** is Mistral AI's largest sparse Mixture-of-Experts (MoE) language model, released in April 2024. With 141 billion total parameters but only ~39 billion active during inference, it delivers near-frontier model performance at significantly reduced computational cost. Mistral released the weights under the Apache 2.0 license, making it the largest openly released MoE model at the time of launch. It supports 64K token context and excels across reasoning, math, coding, and multilingual tasks.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **141B MoE** | 141B total params, ~39B active — high quality with efficient inference |
| **Apache 2.0** | Fully open-source including commercial use — largest open MoE at release |
| **64K Context** | Long context window for extended document processing |
| **Multilingual** | Strong across English, French, German, Spanish, Italian |
| **Native Function Calling** | Instruction-tuned variant supports tool use and function calling |
