# Shieldstral-1.0-3B

## Model Overview
**Shieldstral-1.0-3B** is a **3.8B-parameter** text generation model developed by **mistralai**. Built on the `Mistral3ForConditionalGeneration` architecture. Supports en, fr, es, de, it, pt, nl, zh, ja, ko, ar, ru. Released on **2026-07-16**.
