# Wan Streamer 0.2: Real-Time Character Simulation Framework

## Model Overview
**Wan Streamer 0.2** is a real-time character simulation framework allowing users to converse with generated avatars — including humans, animals, or fictional characters — with highly responsive audio-visual synchronization. It outputs at 640px long-edge resolution, streams at 25 frames per second, and operates with approximately 200ms of model-side latency. It is the predecessor to Wan Streamer v0.3 and part of Alibaba's Wan family of video generation models.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **Real-Time Avatar Conversation** | Converse with generated human, animal, or fictional character avatars |
| **25fps Streaming** | Real-time video streaming at 25 frames per second |
| **~200ms Latency** | Near-real-time responsiveness with ~200ms model-side latency |
| **640px Resolution** | High-quality output at 640px on the long edge |
| **Audio-Visual Sync** | Tightly synchronized lip movements and audio responses |
