# Qwen2.5-Coder-32B-Instruct: Alibaba's State-of-the-Art Code LLM

## Model Overview
**Qwen2.5-Coder-32B-Instruct** is Alibaba's flagship code-focused large language model, featuring 32 billion parameters optimized for coding tasks. Released in November 2024, it achieves performance competitive with GPT-4o on code generation benchmarks while remaining fully open-source. Trained on over 5.5 trillion code tokens, it supports 92+ programming languages and excels at code completion, debugging, code explanation, and software engineering tasks.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **Code Specialist** | Trained on 5.5T+ code tokens covering 92+ programming languages |
| **GPT-4o Code-Competitive** | Matches or exceeds GPT-4o on major coding benchmarks |
| **Agentic Coding** | Strong performance on complex multi-step coding tasks and software engineering agents |
| **Long Context** | 128K token context window for large codebases and project-level understanding |
| **Open-Source** | Fully open weights available on HuggingFace |
