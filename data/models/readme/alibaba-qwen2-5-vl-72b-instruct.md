# Qwen2.5-VL 72B Instruct

## 📌 Model Overview

Qwen vision-language model for visual reasoning, documents, and agent tasks

**Qwen2.5-VL 72B Instruct** is a **Open Weights** model developed by **Alibaba**, released on **2024-09-01**. It is designed primarily for **Multimodal General** workloads. Featuring a **131K tokens** context window and **72B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
