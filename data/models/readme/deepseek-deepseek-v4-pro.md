# DeepSeek V4 Pro

## 📌 Model Overview

Open MoE flagship with million-token context for coding and long agent runs

**DeepSeek V4 Pro** is a **Open Weights** model developed by **DeepSeek**, released on **2026-04-24**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **1M tokens** context window and **Undisclosed** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
