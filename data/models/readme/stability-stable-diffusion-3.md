# Stable Diffusion 3 Medium: Multimodal Diffusion Transformer

## Model Overview
**Stable Diffusion 3 Medium** is Stability AI's latest open-weights image generation model, released in June 2024. It uses a novel **Multimodal Diffusion Transformer (MMDiT)** architecture with separate weights for image and text processing, delivering improved typography rendering, better prompt adherence, and higher image quality compared to SD 2.x. With approximately 2 billion parameters and flow matching training, it runs efficiently on consumer-grade GPUs.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **MMDiT Architecture** | Separate image and text weight streams improve multimodal understanding |
| **Improved Text Rendering** | Significantly better at generating legible text inside images |
| **Flow Matching** | Uses rectified flow matching for faster, higher-quality generation |
| **Consumer-Friendly** | Designed to run on consumer GPUs with adequate VRAM |
| **Open Weights** | Released under Stability AI Community License for developers and creators |
