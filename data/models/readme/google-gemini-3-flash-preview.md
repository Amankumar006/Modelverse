# Gemini 3 Flash Preview

## 📌 Model Overview

New Gemini flash lane bringing frontier-style multimodal reasoning to cheaper runs

**Gemini 3 Flash Preview** is a **Api Only** model developed by **Google DeepMind**, released on **2025-12-17**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **1.0M tokens** context window and **Undisclosed** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
