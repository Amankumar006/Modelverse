# LingBot-World 2.0: Hour-Long Real-Time Interactive World Model

## Model Overview
**LingBot-World 2.0** is an advanced interactive world model developed by Robbyant (Ant Group), released in July 2026. It supports continuous, hour-long real-time video generation at 720p/60fps with zero quality drift — enabling persistent, interactive 3D worlds that evolve in response to user inputs. Its dual-agent mechanism (Pilot Agent + Director Agent) allows for dynamically evolving environments with scripted events and multiplayer persistence within a single generated world.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **Hour-Long Generation** | Continuous 720p/60fps generation for up to 1 hour with no quality degradation |
| **Dual-Agent Mechanism** | Pilot Agent handles user inputs; Director Agent manages scripted scene events |
| **Multiplayer Support** | Multiple users can persist within and interact in the same generated world |
| **Zero Quality Drift** | Maintains visual coherence and world consistency over long generation windows |
| **Apache 2.0** | Open-weights release enabling self-hosted deployment |
