# Qwen3-Next 80B-A3B (Thinking)

## 📌 Model Overview

Efficient Qwen thinking model for local reasoning, math, and coding agents

**Qwen3-Next 80B-A3B (Thinking)** is a **Open Weights** model developed by **Alibaba**, released on **2025-09-01**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **131K tokens** context window and **80B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
