# Qwen3.5 9B

## 📌 Model Overview

Qwen instruction model for multilingual chat, reasoning, and tool use

**Qwen3.5 9B** is a **Open Weights** model developed by **Alibaba**, released on **2026-02-23**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **262K tokens** context window and **9B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
