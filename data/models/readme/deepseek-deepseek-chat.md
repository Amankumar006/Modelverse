# DeepSeek Chat

## 📌 Model Overview

DeepSeek chat model for instruction following, coding, and analysis

**DeepSeek Chat** is a **Open Weights** model developed by **DeepSeek**, released on **2025-12-01**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **1M tokens** context window and **Undisclosed** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
