# Motif-3-Beta

## Model Overview
**Motif-3-Beta** is a **314.8B-parameter** Mixture-of-Experts text generation model developed by **Motif-Technologies**. Built on the `MotifForCausalLM` architecture. Supports en, ko. Released on **2026-07-20**.
