# Qwen3.6 35B-A3B

## 📌 Model Overview

Open multimodal Qwen MoE for local agents that need vision, audio, and code

**Qwen3.6 35B-A3B** is a **Open Weights** model developed by **Alibaba**, released on **2026-04-17**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **262K tokens** context window and **35B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
