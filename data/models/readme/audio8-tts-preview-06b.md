# Audio8-TTS-Preview-0.6b

## Model Overview
**Audio8-TTS-Preview-0.6b** is a **601M-parameter** text to speech model developed by **Audio8**. Built on the `ArkttsModel` architecture. Supports yue, zh, nl, en, fr, de, it, ja, ko, pl, es. Released on **2026-07-28**.
