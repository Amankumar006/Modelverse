# GPT-5.5

## Model Overview
GPT-5.5 (internally codenamed "Spud") is an advanced AI model developed by OpenAI, officially released on April 23, 2026. Billed as a "new class of intelligence for coding and professional work," it represents a major architectural update—the first fully retrained base model since GPT-4.5. GPT-5.5 features a unified omnimodal architecture capable of natively processing text, images, audio, and video without relying on separate specialized models.

## Capabilities
- **Agentic Workflows:** Designed specifically for complex, multi-step agentic tasks. It can understand high-level goals, plan processes, and use tools such as browsers and computer applications autonomously.
- **Omnimodal Processing:** Natively handles multimodal inputs (text, image, audio, video) seamlessly.
- **Self-Verification:** Capable of verifying its own work, heavily reducing the need for constant human intervention.
- **Large Context Window:** Supports an extensive 1M+ token context window.
- **Hardware Co-design:** Maintains per-token latency comparable to GPT-5.4 due to optimization with NVIDIA's GB200/300 systems.

## Example Use Cases
- Autonomous agentic coding tasks requiring minimal human oversight.
- Complex data analysis and reasoning over large codebases (leveraging the 1M+ token context window).
- Seamless multimodal interaction handling image, audio, and text simultaneously in real-time environments.

## Performance & Benchmarks
At its release, GPT-5.5 showcased state-of-the-art results:
- **Terminal-Bench 2.0:** 82.7%, outperforming leading competitors like Claude Opus 4.7 at the time.
- **OSWorld-Verified:** 78.7%, edging out human baselines and competing frontier models.
- **FrontierMath (Tiers 1–3):** 51.7%.

## Intended Use & Limitations
**Intended Use:** Aimed at developers and professionals requiring autonomous reasoning, complex coding, and large-scale multimodal processing.
**Limitations:** While highly capable, it has since been succeeded by the GPT-5.6 family (Sol, Terra, Luna) which offers superior intelligence, efficiency, and lower latency for more cost-sensitive or complex workloads.
