# Fara1.5-27B

## Model Overview
**Fara1.5-27B** is a **27.4B-parameter** image text to text model developed by **microsoft**. Built on the `Qwen3_5ForConditionalGeneration` architecture. Supports en. Released on **2026-07-17**.
