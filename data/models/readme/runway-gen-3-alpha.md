# Runway Gen-3 Alpha: Professional Video Generation Model

## Model Overview
**Runway Gen-3 Alpha** is Runway's third-generation video generation model, released in June 2024. Built for professional filmmakers and creators, Gen-3 Alpha delivers high-fidelity video generation with fine-grained structural controls, temporal consistency, and robust character and visual style consistency across scenes. It represents a major quality leap over Gen-2, producing cinematic-quality footage directly from text or image prompts.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **High-Fidelity Video** | Generates photorealistic, high-quality video clips with cinematic detail |
| **Camera Motion Control** | Fine-grained control over camera movement, angles, and physics |
| **Character Consistency** | Maintains visual identity and style consistency across frames |
| **Professional Workflow** | Designed for integration into professional filmmaking and creative production |
| **Text + Image Input** | Supports text-to-video and image-to-video generation |
