# L2P: Unlocking Latent Potential for Pixel Generation

## Model Overview
L2P (Latent-to-Pixel) is an efficient transfer paradigm for pixel-space diffusion models developed by researchers from Nanjing University (NJU-PCALab) in collaboration with Tencent Youtu Lab. Traditional Latent Diffusion Models (LDMs) rely heavily on Variational Autoencoders (VAEs) for lossy spatial compression, introducing memory bottlenecks and visual artifacts at high resolutions. L2P discards the VAE entirely and introduces large-patch tokenization to enable direct, high-fidelity pixel-space generation up to native 4K, 8K, and 10K resolutions.

## Key Capabilities & Features
- **VAE-Free Architecture:** Removes VAE spatial compression to eliminate memory bottlenecks and latent decoding artifacts.
- **Prior Transfer Paradigm:** Transfers generative priors from pre-trained LDMs by freezing core intermediate layers and training shallow adapter layers alongside a specialized Detailer Head.
- **Synthetic Data Training:** Achieves rapid convergence using purely synthetic image corpora generated by existing LDMs without real-world dataset collection.
- **Ultra-High Resolution Scaling:** Native support for 1K, 4K, 8K, and up to 10K image generation.
- **Compute Efficiency:** Can be trained efficiently on consumer-grade GPU setups (e.g., 8 GPUs).

## Performance & Benchmarks
- **GenEval:** Achieves **93%** of source LDM generative performance.
- **DPG-Bench:** Matches the dense prompt-following performance of original LDMs while executing directly in pixel space.

## Quickstart Usage Code

```python
import torch
from diffsynth.pipelines.z_image_L2P import ZImagePipeline, ModelConfig

main_model_path = "/path/to/model-1k-merge.safetensors"
text_encoder_paths = [
    "/path/to/Z-Image-Turbo/text_encoder/model-00001-of-00003.safetensors",
    "/path/to/Z-Image-Turbo/text_encoder/model-00002-of-00003.safetensors",
    "/path/to/Z-Image-Turbo/text_encoder/model-00003-of-00003.safetensors",
]
tokenizer_path = "/path/to/Z-Image-Turbo/tokenizer"

pipe = ZImagePipeline.from_pretrained(
    torch_dtype=torch.bfloat16,
    device="cuda",
    model_configs=[
        ModelConfig(path=[main_model_path]),
        ModelConfig(path=text_encoder_paths),
    ],
    tokenizer_config=ModelConfig(path=tokenizer_path),
)

image = pipe(
    prompt="A detailed 4K landscape of foggy mountains at sunrise",
    seed=42,
    num_inference_steps=30,
    cfg_scale=2.0,
    height=1024,
    width=1024,
)
image.save("output_l2p.png")
```
