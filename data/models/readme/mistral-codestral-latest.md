# Codestral (latest)

## 📌 Model Overview

Mistral code model for completions, refactors, and developer IDE workflows

**Codestral (latest)** is a **Open Weights** model developed by **Mistral AI**, released on **2024-05-29**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **256K tokens** context window and **Undisclosed** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
