# Nemotron Mini 4B Instruct

## 📌 Model Overview

Compact Nemotron model for efficient reasoning and deployable AI agents

**Nemotron Mini 4B Instruct** is a **Open Weights** model developed by **NVIDIA**, released on **2024-08-21**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **128K tokens** context window and **4B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
