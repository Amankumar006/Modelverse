# High3: Tencent's Efficient MoE Reasoning Model

## Model Overview
**High3** (also referred to as Hy3) is Tencent's open-weights Mixture-of-Experts (MoE) language model focused on reasoning, math, and agentic coding. With 295 billion total parameters but only 21 billion active during inference, High3 punches significantly above its weight class on agentic benchmarks — competing closely with models 4-5x its size. It demonstrates exceptional performance in "vibe coding" UI components and web applications, making it particularly useful for front-end development tasks.
