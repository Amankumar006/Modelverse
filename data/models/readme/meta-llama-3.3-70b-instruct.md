# Llama-3.3-70B-Instruct

## 📌 Model Overview

Popular open Llama workhorse for multilingual chat, coding, and self-hosting

**Llama-3.3-70B-Instruct** is a **Open Weights** model developed by **Meta**, released on **2024-12-06**. It is designed primarily for **Chat Reasoning** workloads. Featuring a **128K tokens** context window and **70B** parameter count, it offers robust performance for enterprise integration, developers, and researchers.
