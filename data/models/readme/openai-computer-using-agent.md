# Computer Using Agent (CUA): OpenAI's Computer Control Model

## Model Overview
**Computer Using Agent (CUA)** is OpenAI's model for computer use, allowing AI to interact with computers through screenshot observation and simulated mouse/keyboard actions. Released in January 2025, CUA enables fully autonomous computer operation — browsing the web, filling forms, running applications, and completing multi-step tasks on a real computer interface. It combines vision understanding with action generation, making it one of the first broadly deployed computer-use AI agents.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| **Full Computer Control** | Controls mouse clicks, keyboard input, scrolling, and multi-app workflows |
| **Screenshot-Based** | Operates by observing screenshots and planning actions accordingly |
| **Web Browsing** | Navigates real websites, fills forms, and clicks through multi-step flows |
| **OSWorld Performance** | Achieved 38.1% on OSWorld benchmark at launch — state-of-the-art at release |
| **API Integration** | Available via OpenAI API as a specialized agent model |
