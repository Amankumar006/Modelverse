# Grok Imagine Image (xAI)

## 📌 Model Overview

**Grok Imagine Image** is xAI's high-speed image generation model integrated into Grok and the X platform. Designed for fast creative iteration and real-time visual design, it delivers an average generation latency of **6.4 seconds per 1K image** at an affordable rate of **$0.020 per image**.

---

| Feature | Details |
|:---|:---|

| **Fast Inference** | **6.4s latency** per 1K image rendering |
| **Cost Efficiency** | **$0.020 per 1K resolution image** |
