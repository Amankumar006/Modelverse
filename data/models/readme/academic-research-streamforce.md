# StreamForce

## 📌 Model Overview

StreamForce (Streaming Video Generation with Streaming Force Control) is a causal, unified framework for real-time streaming video generation developed by Northeastern University (NEU-VI Lab). It enables physically grounded interactive control over video rollouts via continuous, time-varying force inputs at up to 16.6 FPS.

**StreamForce** is a **Research Preview** model developed by **Academic/Research**, released on **2026-06-01**. It is engineered primarily for **Video Generation** workloads. Featuring a **128K tokens** context window and **Undisclosed** parameter count, it offers robust performance for enterprise integration, developers, and researchers.

---

## ✨ Key Features & Capabilities

| Feature | Description |
|:---|:---|
| **Context Window** | 128K tokens capacity for extended prompts and multi-turn workflows |
| **Primary Task** | Optimized for Video Generation |
| **Deployment** | self-hostable |
| **Modality** | image, video |
| **Physically Grounded Streaming Control** | Physically Grounded Streaming Control: Accepts continuous time-varying force vectors to dynamically manipulate video streams |
| **Causal Autoregressive Architecture** | Causal Autoregressive Architecture: Generates video sequentially from an initial image frame for low-latency interactive steerability |
| **Real-Time Speed (up to 16.6 FPS)** | Real-Time Speed (up to 16.6 FPS): Efficient force-controllable distillation pipeline enables streaming generation on a single GPU |
| **Unified Force Signal Representation** | Unified Force Signal Representation: Combines local impulses and global environmental forces into a unified control signal space |
| **Physical & Photometric Realism** | Physical & Photometric Realism: Maintains object persistence and motion plausibility under interactive user force interventions |
