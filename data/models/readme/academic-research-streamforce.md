## ✨ Key Features

- Physically Grounded Streaming Control: Accepts continuous time-varying force vectors to dynamically manipulate video streams
- Causal Autoregressive Architecture: Generates video sequentially from an initial image frame for low-latency interactive steerability
- Real-Time Speed (up to 16.6 FPS): Efficient force-controllable distillation pipeline enables streaming generation on a single GPU
- Unified Force Signal Representation: Combines local impulses and global environmental forces into a unified control signal space
- Physical & Photometric Realism: Maintains object persistence and motion plausibility under interactive user force interventions
